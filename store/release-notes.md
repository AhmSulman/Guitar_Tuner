# Release notes ("What's new")

Max **500 characters per language**. Play Console asks for this on every release.

## For the closed test — v1.0.2

```
First test build. Thanks for installing.

Point your phone's mic at a guitar and tune. Pick a tuning from the dropdown — 12 are
included, from Standard to Drop C and DADGAD. Tap a string to lock onto it when you're
retuning a long way.

Please leave it installed for the full two weeks, even if you don't open it again. If
anything looks wrong, just reply to the email that invited you.
```
